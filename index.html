02 / Produit phare02 / Flagship

Castellan

Le gardien du château. Une console d'administration de domaine pensée pour administrer, pas pour pénétrer, avec la sécurité comme première exigence.

The keeper of the castle. A domain administration console built to administer, not to break in, with security as its first requirement.

01

Appliance et agentAppliance and agent

Un serveur dédié et un agent généré par lui. Toutes les connexions vers les machines administrées passent par cet agent, et seuls les utilisateurs authentifiés peuvent le télécharger.

A dedicated server and an agent it generates. Every connection to managed machines goes through that agent, and only authenticated users can download it.

02

Windows, Linux, réseauWindows, Linux, network

Les serveurs Windows et Linux s'administrent depuis la même console. Les serveurs Linux et les équipements réseau passent par SSH.

Windows and Linux servers are managed from the same console. Linux servers and network devices are reached over SSH.

03

Console distante intégréeBuilt-in remote console

Un accès bureau distant directement dans l'interface, à la manière des consoles d'hyperviseur.

Remote desktop access right inside the interface, the way hypervisor consoles work.

04

Actions signéesSigned actions

Au choix lors de l'installation : un mandat signé en début de session, ou une appliance de confiance.

Chosen at installation: a mandate signed at the start of each session, or a trusted appliance.

05

Aucune dépendance externeNo external dependencies

Conçu pour les réseaux sans accès Internet : ni CDN, ni police en ligne, ni appel sortant.

Built for networks with no Internet access: no CDN, no web fonts, no outbound calls.

06

SIEM en optionOptional SIEM

Une option d'installation permet à Castellan de collecter et corréler les événements de sécurité.

An installation option lets Castellan collect and correlate security events.

03 / Principes03 / Principles

Ce qui ne se négocie pasWhat is not up for negotiation

Sûr par défautSecure by default

La configuration livrée est la plus restrictive. Ouvrir doit être un choix, jamais un oubli.

The shipped configuration is the most restrictive one. Opening up must be a choice, never an oversight.

AutonomeSelf-contained

Tout fonctionne hors ligne. Ce qui n'appelle personne ne peut pas être détourné.

Everything works offline. What calls no one cannot be hijacked.

SimpleSimple

Entre deux architectures sûres, la plus simple l'emporte. La complexité est une faille qui attend son heure.

Between two secure designs, the simpler one wins. Complexity is a vulnerability biding its time.

ÉprouvéBattle-tested

Chaque protection est pensée face à une attaque réelle. On teste ce qu'on construit comme un adversaire le ferait.

Every safeguard is designed against a real attack. What we build, we test the way an adversary would.
